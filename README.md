# English localization patch for `@dely0/dsh-personal-workbench`

Переиспользуемый патч, переводящий плагин «个人工作台 / Personal Workbench» **полностью на английский**:
интерфейс, описания инструментов и промпты для ИИ, файлы экспертов-ролей и документацию.

Патч **не правит установленную копию напрямую** — он состоит из словаря и скриптов, которые можно
применять повторно (в том числе после `dsh plugin update`, когда перевод слетит).

## Что внутри

| Файл / каталог | Назначение |
|---|---|
| `dictionary/strings.json` | Полный словарь `китайский → английский` для всех строковых литералов кода (4 257 записей). |
| `dictionary/ui.json` | Подмножество — строки интерфейса (идут в `EN_MESSAGES`). |
| `dictionary/backend.json` | Подмножество — не-UI строки (описания инструментов, промпты, ошибки, логи). |
| `translated/personas/*.md` | 15 переведённых ролей-экспертов (с английскими именами файлов). |
| `translated/README.md`, `translated/methodology.md` | Переведённая документация. |
| `rename-map.json` | Карта переименований `оригинал → английский` для `.md` ролей. |
| `dictionary-names.json` | Словарные данные (типы/статусы/приоритеты и т.п.) + миграция БД. |
| `apply.mjs` | Применяет перевод к каталогу плагина. |
| `migrate.mjs` | (Опционально) мигрирует названия словарей в существующей БД. |

## Как применить

### 1. Перевести код и файлы

```powershell
node apply.mjs
```

По умолчанию цель — установленный плагин
`C:\Users\Nikita\.dsh\profiles\desktop\node_modules\@dely0\dsh-personal-workbench`.

Рекомендуется сначала прогнать на **копии** (dry-run):

```powershell
# скопировать плагин
robocopy "C:\Users\Nikita\.dsh\profiles\desktop\node_modules\@dely0\dsh-personal-workbench" `
         "D:\workbench-en-test" /E /NFL /NDL /NJH /NJS > $null
# применить к копии
node apply.mjs "D:\workbench-en-test"
```

`apply.mjs` делает:
1. Дополняет таблицу `EN_MESSAGES` (в `lib/shared/i18n.js`) английскими переводами строк интерфейса.
2. Заменяет китайские строковые литералы на английские во всех остальных `.js`/`.mjs`
   (описания инструментов, промпты, сообщения об ошибках, названия сидов, «сырой» текст UI).
   Аргументы `t(...)` (ключи i18n) и комментарии **не трогаются**.
3. Заменяет `.md` ролей (переведённое содержимое + переименование файлов) и документацию.

После этого перезапустите DSH. Интерфейс, промпты ИИ и роли станут английскими.

### 2. (Опционально) Мигрировать существующую БД

Если плагин уже использовался, названия словарей (типы задач, статусы, приоритеты и т.п.)
уже сохранены в БД по-китайски. `apply.mjs` переводит только код (сиды для **новых** установок),
а для **существующей** БД выполните:

```powershell
node migrate.mjs
# или явно указать путь к БД:
node migrate.mjs "C:\Users\Nikita\.dsh\workbench\workbench.db"
```

Скрипт делает резервную копию БД и обновляет **только** встроенные строки (`builtin=1`), которые
до сих пор несут оригинальное китайское название. Названия, которые вы уже переименовали вручную,
не затрагиваются.

## Что переводится и что нет

**Переводится:**
- Интерфейс (сайдбар, календарь, задачи, настройки, диалоги) — через `EN_MESSAGES`.
- Описания инструментов и промпты для ИИ (то, что получает модель).
- Сообщения об ошибках, статусы, логи, сиды словарей.
- 15 ролей-экспертов (содержимое + имена файлов).
- `README.md` и `assets/expert-generation/methodology.md`.

**Не переводится (намеренно):**
- **Комментарии в коде** (`//`, `/* */`) и JSDoc в `.d.ts` — они не видны пользователю и не влияют на работу.
- **`THIRD_PARTY_NOTICES.md`** — юридические уведомления о сторонних лицензиях, их нельзя переводить.
- **`assets/personas` имена, на которые ссылается код** — см. ниже про i18n.

## Проверка (выполнена)

Патч был применён к копии плагина и проверен:

- **Все 143 `.js`/`.mjs` файла** в `lib/` проходят `node --check` (синтаксис не сломан).
- Остаточный китайский в строковых литералах (без комментариев) — **0** во всех файлах,
  кроме `lib/shared/i18n.js`, где остаются только **ключи i18n** (`t('…')`), что и задумано.
- Описания инструментов (`lib/tools.js`) и промпты (`lib/index.js`) — полностью английские.
- 15 ролей переименованы и переведены; китайских имён файлов не осталось.
- `migrate.mjs` проверен на копии БД: 61 название словаря и 4 описания приоритетов обновлены на английский.

## Важные замечания

- **Локали `zh-CN` / `en-US`.** Интерфейс переводится через штатный механизм i18n
  (`t(...)` + `EN_MESSAGES`), поэтому китайская локаль сохраняется как запасная. Однако
  **описания инструментов и промпты ИИ** не проходят через i18n — они заменяются напрямую и
  становятся английскими всегда.
- **Перевод слетит при `dsh plugin update`.** После обновления просто запустите `node apply.mjs`
  (и при необходимости `node migrate.mjs`) снова.
- **Ключи i18n.** Китайский текст в вызовах `t('…')` оставлен как есть (это ключи словаря);
  английский подставляется из `EN_MESSAGES` в момент отображения. Поэтому остаточный китайский
  в исходниках `lib/` — это ожидаемо (ключи и комментарии), а не недоперевод.
- **Словарные данные.** Названия типов/статусов/приоритетов хранятся в БД (таблица `dictionaries`)
  и редактируются пользователем в «Настройки → Управление словарями». Для существующей БД нужна
  миграция (`migrate.mjs`); новые установки получат английские названия из переведённых сидов.
